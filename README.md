# Обработка встреч

Приложение для macOS: записывает рабочие встречи, распознаёт речь на самом
компьютере и собирает из транскрипта саммари. Готовое саммари можно сохранить в
Заметки или выгрузить в Notion.

## Установка

Нужно: macOS 13 или новее, аккаунт [Claude](https://claude.ai) с подпиской,
дающей доступ к Claude Code, и около 4 ГБ свободного места. Homebrew, Node и
Xcode не требуются — приложение само скачивает всё, чем пользуется.

1. **Скачать** `MeetingApp.zip` из раздела [Releases](../../releases).
2. **Распаковать** двойным щелчком и перетащить `MeetingApp.app` в «Программы».
3. **Открыть первый раз.** macOS откажется запускать приложение: оно подписано
   самодельным сертификатом, Apple за него не ручается. Нажми «Готово», открой
   **Системные настройки → Конфиденциальность и безопасность**, найди внизу
   строку про MeetingApp и нажми **«Всё равно открыть»**. Дальше приложение
   открывается как любое другое.
4. **Поставить компоненты.** В окне первого запуска нажми установку: приложение
   скачает распознавание речи, работу с аудио и Claude Code, а затем попросит
   войти в твой аккаунт Claude. Модель распознавания весит 2,9 ГБ — это самая
   долгая часть.

Разрешения macOS приложение запросит само, когда они понадобятся: микрофон и
запись экрана — чтобы писать обе стороны разговора (сохраняется только звук),
календарь — чтобы предлагать запись перед встречей, Заметки — чтобы сохранять
туда саммари.

## Где лежат данные

Записи, транскрипты и саммари хранятся в папке `~/MeetingApp` на твоём
компьютере. Распознавание идёт локально. Саммари собирает Claude Code под твоим
аккаунтом. В Notion и Заметки саммари попадает только по нажатию кнопки — само
приложение никуда ничего не отправляет.

Токен Notion, если он нужен, хранится в Связке ключей macOS. Настройки — словарь
терминов и список своих платформ видеосвязи — лежат в настройках приложения и
никуда не передаются.

## Сборка из исходников

Нужны Xcode Command Line Tools (Swift 5.9+).

```bash
cd MeetingApp && ./build_app.sh
```

Тестовая сборка — `./build_app.sh --test`: отдельная папка данных, отдельные
настройки и разрешения, рабочие данные она не трогает. Тесты — `swift run
MeetingAppTests`. Выпуск и откат рабочей сборки — `./release_prod.sh` и
`./rollback_prod.sh`.

**Запись разговоров.** За законность записи встреч и за уведомление их
участников отвечает тот, кто пользуется приложением. В ряде стран и компаний
